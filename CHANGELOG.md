# Changelog

## Unreleased

- New sources: Codex CLI, Gemini CLI, Qwen Code, Goose, Amp, Cline, Roo Code, Kilo Code and Zed.
- App picker on first launch (and with `a`): check the apps you use; toktop finds their data.
- dsh and Aider show copyable setup instructions for your AI agent.
- `[colors]` in the config file overrides a source's colour.

## 0.1.0 — 2026-11-24

First public release.

- Textual dashboard: KPIs, yearly heatmap, stacked daily chart, calendar, models, sessions and prices.
- Sources: Claude Code, opencode, zcode, dsh and OpenBot (no double counting).
- Persistent history: counts survive uninstalled apps and pruned sessions.
- Prices fetched daily from OpenRouter, with a built-in fallback table.
- `--demo` mode with made-up data, `--text` summary, config file, English and Spanish.
